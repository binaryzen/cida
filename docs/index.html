CIDA

Two independent applications of the same underlying method.

Both projects start from the same shape of problem: a large set of individual decisions with no built-in grouping. 439 members of the 118th Congress casting roll-call votes. 1,000 public bug reports filed against a Git client over nearly a decade. Neither dataset comes labeled with the axes that actually explain the variation, so the first step is unsupervised — reduce the raw votes or the raw ticket text down to a handful of components (PCA for the votes, NMF for the text) that account for most of what differs from one record to the next.

What matters more is what happens after that reduction. Each component gets checked against data the decomposition never saw. The congressional components are compared against DW-NOMINATE, an independent ideology score built from a different methodology, and against FEC contribution records. The ticket components are compared against resolution outcome and triage status, fields the topic model was never shown. In both cases, at least one component holds up under that check and turns out to be doing something the obvious explanatory variable — party, product priority — doesn't capture by itself.

None of this depends on Congress or bug trackers specifically. The same recipe applies to any domain with a large number of comparable individual decisions or texts, plus a second, independent dataset to test the resulting structure against: judicial opinions and case outcomes, product reviews and return rates, clinical notes and readmission records. Whether it finds anything worth reporting in a given domain depends entirely on whether real structure connects the two datasets — the method doesn't guarantee that, it just gives you a way to check.

Iterations

Iteration 1

Congressional Interest Dimension Analysis

PCA over 118th Congress roll-call votes (354 House, 85 Senate), checked against DW-NOMINATE and FEC contribution data. Finds a House voting dimension independent of party and of both existing NOMINATE axes.

 Iteration 2

Customer Issue Dimension Analysis

NMF and PCA over 1,000 public Sourcetree for Windows bug tickets (2013–2023). Finds that half the backlog was never triaged and that resolution depends on team decisions, not ticket content.
